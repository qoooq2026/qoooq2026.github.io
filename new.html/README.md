# QoooQ – Website

台湾のショート動画マーケティング会社 QoooQ のサイト（日本語／繁體中文）。

## GitHub Pages で公開する手順
1. GitHubで新しいリポジトリを作成（例：`qoooq-site`、Public）
2. このフォルダの中身をすべてアップロード（「Add file → Upload files」）
3. **Settings → Pages** で Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/qoooq-site/` で公開されます
